Each retry comment requires permission for its PR or tag. The label requirement applies only to PRs.

  1. Read-only{{if not .Snapshot.WritesEnabled}} (active){{end}}. The assistant reads GitHub and posts no comments. Start the assistant without --enable-writes.
  2. Interactive{{if and .Snapshot.WritesEnabled .Snapshot.Interactive}} (active){{end}}. Confirm each eligible retry comment before the assistant posts it. If the label requirement is on, GitHub must also report the label for the PR. Select Confirm each retry comment.
  3. Only labeled{{if and .Snapshot.WritesEnabled .Snapshot.RequirePRLabel (not .Snapshot.Interactive)}} (active){{end}}. The assistant posts eligible retry comments automatically. It posts to a PR only if GitHub reports {{prCommentLabel}}. Clear Confirm each retry comment. Select Require the label for PR comments.
  4. Full auto{{if and .Snapshot.WritesEnabled (not .Snapshot.Interactive) (not .Snapshot.RequirePRLabel)}} (active){{end}}. The assistant posts eligible retry comments automatically. A PR can receive comments without the label. Clear both checkboxes.

For a mode that posts comments, start with --enable-writes. Configure the release. Change the checkboxes in Application settings. Select Save settings.
